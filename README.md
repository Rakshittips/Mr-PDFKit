# 📄 Mr-PDFKit

> **Fast, Secure & Modern Web-Based PDF Toolkit**  
> Streamline your PDF workflow directly in your browser without uploading your sensitive files to external servers!

---

## 🚀 Overview

**Mr-PDFKit** is an all-in-one, client-side web utility developed by **Rakshittips**. It allows users to convert, merge, split, compress, and edit PDF files effortlessly. Designed with privacy, performance, and modern UI in mind, all operations are processed locally in your browser to ensure maximum data privacy.

---

## ✨ Key Features

- 🔒 **100% Privacy & Security:** Client-side processing ensures your documents never leave your browser.
- ⚡ **Lightning Fast:** Powered by lightweight web technologies for instantaneous document rendering and editing.
- 🛠️ **PDF Utility Suite:**
  - **Merge PDFs:** Combine multiple PDF documents into a single organized file.
  - **Split & Extract:** Separate pages or ranges into individual standalone PDFs.
  - **Image to PDF / PDF to Image:** Convert JPG/PNG images to PDF format or extract PDF pages as images.
  - **Compress & Optimize:** Reduce file size while preserving high visual quality.
  - **Watermark & Rotate:** Custom security watermarks and flexible page orientation fixes.
- 📱 **Fully Responsive:** Sleek, modern iOS/Android-friendly UI accessible across desktops, tablets, and smartphones.
